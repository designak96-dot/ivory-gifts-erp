# Ivory Gifts ERP

Production-ready Laravel 12 application for Ivory Gifts accounting and operations on cPanel/PHP 8.4.1+.

Included modules: Owner setup and authentication, roles and permissions, CRM, product catalog, quotations, sales orders, invoicing, partial payments, VAT, production board and costing, delivery notes and POD, suppliers, purchasing and stock receipts, inventory movements, expenses, double-entry accounting, financial/operational reports, audit logs, CSV import/export, WooCommerce webhook queue, backups, and system health.

Use `INSTALL-CPANEL.md` for installation. Use `docs/UPDATING-CPANEL.md` for future releases and `docs/BACKUP-ROLLBACK.md` before any restore or rollback.
